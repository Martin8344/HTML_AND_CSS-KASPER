# KASPER - Creative Agency Template

A modern, responsive landing page for a creative agency. Built with HTML, CSS, and JavaScript.

🔗 **Live Demo:** https://martin8344.github.io/HTML_AND_CSS-KASPER/

## Features
- Fully responsive design for all devices
- Modern landing page sections: Hero, Services, Portfolio, Pricing, Contact
- Clean UI with smooth layout
- Portfolio gallery with hover effects

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
